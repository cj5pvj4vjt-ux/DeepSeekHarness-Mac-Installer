# 如何准备「本机 web profile」（构建种子前的准备）

`sync-profile-seed.sh` 会把本机 `~/.dsh/profiles/web` 的插件全家桶同步进 .app 种子。
构建前请先把 profile 装到你满意的状态。

## 前置

- macOS arm64（Apple Silicon）
- Node.js ≥ 20（建议 22/26）+ pnpm
- 全局安装 DeepSeek Harness CLI：

```bash
npm i -g @deepseek-ai/dsh
dsh --version   # 0.1.0-rc.6
```

## 初始化 profile 并安装插件

```bash
# 首次启动会创建 ~/.dsh/profiles/web 骨架
dsh web --help >/dev/null 2>&1 || true

cd ~/.dsh/profiles/web

# 在 package.json 的 dsh.profile.bundles 与 dependencies 里声明插件后：
pnpm install --ignore-scripts=false
```

## 验证

```bash
dsh web   # 本地起服务，确认插件全部加载、界面正常
```

确认无误后即可运行构建链打包：

```bash
./scripts/build-all.sh "<原始 DeepSeek Harness.app>" "<安装器.app>" ./out
```

## 隐私红线

同步前确保 `~/.dsh` 里没有个人数据混入：
- ✅ 允许：`profiles/web`（代码 + 依赖 + 配置骨架）、`profiles/web/.dsh-market`
- ❌ 禁止：`~/.dsh/.credentials.yaml`、`sessions/`、`storages/`、`task-board/`、
  `attachments/`、个人 `settings.yaml` 里的 API Key —— 这些一律**不**进种子。
  （App 首启只会生成一份干净的最小 `settings.yaml`。）
